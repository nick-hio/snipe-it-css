# Porcelain

A light Snipe-IT redesign with white cards, cobalt accents, rounded controls and consistent spacing. Covers the dashboard, lists, detail pages, forms, settings, reports, calendar and login screens.

[Install](../../README.md#install) · [CSS file](custom.css)

Tested with **Snipe-IT v8.8.3, build 26143**, in Chromium at 390, 820, 1024 and 1440 px. Uses system sans-serif fonts and requires no application source changes.

Porcelain uses a fixed light palette. Snipe-IT's dark preference and Branding colour settings do not change this palette. Compatibility with other versions and browsers has not been verified.
